MAYER DISTRIBUTION - PACHET PENTRU GITHUB PAGES

Acest folder este pregatit pentru publicare statica pe GitHub Pages.

IMPORTANT - CONFIDENTIALITATE
- Listele cu soferi, numere de inmatriculare si destinatii interne au fost eliminate din codul public.
- Dupa publicare, deschideti aplicatia si folositi Setari > Backup si restaurare > Restaureaza din backup pentru a importa un fisier JSON creat anterior din aplicatia existenta.
- Nu incarcati niciodata fisierul JSON de backup in repository; acesta poate contine date operationale si istoricul programelor.
- GitHub Pages publica site-ul pe internet. Nu exista autentificare sau server; fiecare dispozitiv pastreaza datele in propriul browser.

PUBLICARE
1. Creati un repository PUBLIC nou pe GitHub, de exemplu MayerDistribution.
2. Incarcati CONTINUTUL acestui folder in radacina repository-ului (index.html trebuie sa fie la nivelul principal).
3. Deschideti Settings > Pages.
4. La Build and deployment alegeti Deploy from a branch, branch main, folder /(root), apoi Save.
5. Asteptati publicarea; adresa va fi https://USERNAME.github.io/MayerDistribution/ (USERNAME este numele contului GitHub; majusculele din numele repository-ului pot fi normalizate in URL).
6. Deschideti adresa pe iPhone in Safari > Partajare > Adauga la ecranul principal.
7. Deschideti aplicatia instalata, intrati in Setari si importati backup-ul JSON.

NOTA
Pastrati backup-ul JSON intr-un loc privat. Nu il incarcati in GitHub. Pentru a actualiza aplicatia ulterior, pastrati aceeasi adresa/origine pentru a pastra stocarea locala de pe dispozitiv.
